# Guia de Cuidados – Smoke & Filhote

Next.js (App Router) + Tailwind app que replica o HTML fornecido, com botões de cópia/impressão.

## Requisitos
- Node.js 18+

## Instalação
```bash
pnpm install # ou npm install / yarn
```

## Desenvolvimento
```bash
pnpm dev # http://localhost:3000
```

## Build
```bash
pnpm build && pnpm start
```

## Notas
- Página única em `app/page.tsx`
- Estilos utilitários em `app/globals.css` + `tailwind.config.ts`
- Botões: imprimir, copiar checklists e resumo mestre
